# PRD 13: "Move like me"

## Goal

On the website, record a few seconds of your own mouse (click a handful of targets), fit the
motion options to it (speed, curve, overshoot, jitter), and get a code snippet:
`createHuman(page, { motion: { ... } })`. Shareable, and it shows the library is tunable rather
than one canned curve.

## Acceptance criteria (thin)

- A page on the site that records in the browser only (no upload), fits options, and shows the
  replay side by side with the recording.
- The snippet works when pasted into the quickstart.
