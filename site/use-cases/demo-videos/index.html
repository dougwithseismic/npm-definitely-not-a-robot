Record your product demo from a script. It still looks like a person made it.

Hand-made screen recordings go stale with every release. A Playwright script can re-record them in seconds, but its video has no cursor, text that appears in one frame and clicks out of nowhere. Add one line and the same script looks like someone using your product.

Where a plain recording falls short

No cursor in the video

A cursor viewers can follow

The demo preset draws an arrow, and a ring on every click, inside the page, so both end up in the recording. It follows the page's real mouse events, so it shows exactly what happened.

Forms fill in one frame

Typing people can read

Text goes in key by key at a steady 50 words a minute, with Shift for capitals, and short pauses between steps so each one lands before the next.

Every take is a reshoot

Same seed, same take

Pass a seed and every run takes the same paths with the same pauses, so a take can be re-recorded frame for frame.

The recipe

Install it next to Playwright with npm install definitely-not-a-robot playwright, save this as record-demo.mjs and run node record-demo.mjs.

examples/record-demo.mjs

Playwright saves WebM; ffmpeg -i videos/<file>.webm demo.mp4 makes an MP4. In Playwright Test, set use: { video: 'on', humanOptions: { preset: 'demo' } } and every test records with a cursor.
