This is the library itself, running in your browser: createHuman with the demo preset, driving this box instead of a browser tab. The grey cursor is what page.click() does: one jump to the dead centre. The indigo one is human.click().

Playwright is built for speed. Sometimes you need a person.

click() teleports to the exact centre and fill() pastes text in one go. Perfect when a test only checks the result. Wrong when your automation has to look or behave like someone using the page.

The cursor teleports

Paths that arc, timed by distance

Far, small targets take longer than near, big ones. Long moves overshoot and correct. Clicks land near the centre, never the edge, and won't go through a cookie banner.

Text appears all at once

Typing with a rhythm

Uneven gaps between keys, faster common letter pairs, pauses between words, Shift for capitals, and typos that get noticed and fixed if you want them.

Every run is different

Seeds replay a run exactly

createHuman(page, { seed: 42 }) gives the same paths and timings every time, so a flaky run can be reproduced and a demo re-recorded frame for frame.
